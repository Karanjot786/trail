# Compare, filter and share

## Compare

The **Compare** menu in the header offers three choices:

- **Previous period**: the range just before this one, of the same length.
- **Custom period**: pick the start date; the comparison covers the same number of days.
- **No comparison**.

One day is always compared with the day before. Today is compared with the same hours of yesterday. The button shows what it compares with, and hovering it shows the dates.

## Filter

Click a row in any panel or table to filter every screen by it. Filters show as chips under the header; remove a chip to widen the view, or **Clear all**. You can filter by page, source, country, device, event and campaign.

Press `F` to add a filter from the keyboard, and `Shift X` to clear them all. Browser Back undoes the last filter.

## Search and jump with ⌘K

`⌘K` (`Ctrl K` on Windows and Linux) opens the command palette. Type to:

- jump to a screen or tab (`G` then a letter also works, for example `G L` for Live);
- switch site or range;
- filter by a page, source, country, device, event or campaign;
- open a saved view;
- run an action: share a link, save the view, add a website, switch theme, collapse the sidebar.

`?` opens the full list of shortcuts.

## Saved views

Press `S` (or the **+** under the sidebar entries) to save the current filters as a named view. It appears in the sidebar and applies those filters on the current screen when clicked. A view never includes an open sheet.

## Share a read-only link

Open **Share a read-only link…** from `⌘K`. Anyone with the link can open that view, read-only: the site, range, comparison and filters are fixed. You choose:

- **Expires after**: 1 day, 7 days, 30 days or never.
- **Hide revenue**: removes Revenue everywhere in the shared view.

Every active link is listed in [Settings → Sharing](/dashboard/settings#sharing), where you can revoke it. A revoked link stops working at once.
