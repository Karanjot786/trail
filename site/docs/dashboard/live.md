# Live

**Live** follows one website at a time; pick one in the site switcher first. It polls every 5 seconds. The sidebar shows the same count of people online, which is distinct visitors with any event in the last 5 minutes.

- A globe and a list show active visitors by place.
- **Live events** is the stream of the last 5 minutes. Filters apply to it.
- **Pause** stops updating. The screen also pauses while the browser tab is hidden. When you are offline it says "as of" the last update and does not refresh.

Click a visitor to open their [journey](/dashboard/activity#journeys).
