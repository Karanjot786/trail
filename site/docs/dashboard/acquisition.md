# Acquisition

Four tabs, each a table you can sort, filter and export:

| Tab | What it shows |
|---|---|
| **Sources** | Grouped by Source, Referrer URL or Channel |
| **AI referrals** | Assistants that sent a referrer. A floor, not a total, because many assistants send none. See [AI visibility](/dashboard/ai-visibility) |
| **Campaigns** | UTM-tagged visits, with source and medium as chips that filter |
| **Landing pages** | The first page of each visit, how well it does, and its top source |

Click a row to filter the dashboard by it. Revenue and goals credit the visit's first source, so these tables, [Conversions](/dashboard/conversions) and [Revenue](/dashboard/revenue) agree row for row.
